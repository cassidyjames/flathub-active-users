Active users over time

Each point is a count of the FreeDesktop SDK platform updates to that branch’s patch release delivered by Flathub for as long as that release was the newest one available—so a release that stayed current for two months counts every installation that updated in those two months. Since multiple branches of the FreeDesktop SDK are actively used by different apps at the same time, summing them would potentially over-count users; instead, estimated active users is based on the highest peak of updates from the past six months.

Because release cadence varies, the window behind each point does too; hover a point to see how long its release was current. A longer window catches installations that update infrequently, so points aren’t directly comparable to each other.
